# Causure GitHub-native synthetic agent

This small repository fixture has two pretend harness components and one protected synthetic
case generator. Pull requests change one marker as data; the generator returns fixed
evidence so the public example can demonstrate approval, abstention, and an honest request
for more evidence without credentials or external services.

The adapter is intentionally educational. A company replaces it with reviewed replay and
evaluation code that produces the same canonical change-case contract.
